Gunakan Personal Access Token dengan Contents: Read and write untuk repository ini. Pada Repository access, pilih Only select repositories, bukan Public repositories (read-only). Opsi Read and write baru muncul setelah repository dipilih. Token hanya dikirim ke api.github.com dan tidak disimpan di situs, kecuali Anda mencentang pilihan di bawah.
